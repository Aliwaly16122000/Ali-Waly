# 🎓 بوابة كلية الهندسة — EngPortal

منصة متكاملة لكلية الهندسة (كل الأقسام) فيها **4 واجهات**: الطالب، المعيد، الدكتور، وإدارة الكلية.
المواد، الشيتات والتسليم، التصحيح ورصد الدرجات، اعتماد الدكتور والإحصائيات، الحضور بالـ QR، الجدول والتذكيرات، المحادثات، والإشعارات الفورية.

> واجهة عربية بالكامل (RTL)، وضع ليلي، وتشتغل على الموبايل كتطبيق (PWA) مع إشعارات حتى والتطبيق مقفول.

---

## المميزات

### 👨‍🎓 الطالب
- يشوف **المواد المسجل فيها** بس (حسب قسمه وفرقته) مع مجموعه في كل مادة.
- **يرفع حل الشيت** (PDF/صور/ZIP) قبل الموعد، ويقدر يعيد التسليم لحد ما يتصحح. التسليم المتأخر بيتعلّم عليه.
- يشوف **درجته وتعليق المصحح** أول ما الدكتور يعتمد الدرجات، مع متوسط وأعلى درجة في الدفعة.
- **تسجيل الحضور بالـ QR** من كاميرا التطبيق أو كاميرا الموبايل العادية، أو بكود من 6 أرقام.
- **جدولي**: مواعيد المحاضرات والسكاشن الخاصة بسكشنه، مع تذكير قبل كل موعد.
- نسبة الحضور، و**إنذار غياب** تلقائي لو نزل عن 75%.
- **محادثة** مع دكتور ومعيد كل مادة (مع إرفاق ملفات، وعلامة قراءة ✓✓، وحالة "يكتب الآن…").

### 🧑‍💻 المعيد
- ينزّل شيتات وكويزات ومحاضرات وإعلانات (الطلاب بيوصلهم إشعار فوراً).
- **شاشة تصحيح سريعة**: تحميل حل كل طالب، كتابة الدرجة والتعليق والتنقل بـ Enter، فلترة بالسكشن و"سلّم ولم يُصحّح"، و"صفر لمن لم يسلّم".
- لما يخلص: **"ارفع للدكتور"** ← بيتقفل التعديل والدكتور يوصله إشعار.
- الدرجات **بتتجمع تلقائياً** في كشف الدرجات.

### 👨‍🏫 الدكتور
- **يعتمد وينشر** الدرجات للطلاب، أو يرجّعها للمعيد بملاحظة.
- **إحصائيات**: توزيع الدرجات، توزيع التقديرات، متوسط كل تقييم، نسبة النجاح، الانحراف المعياري، مقارنة السكاشن، نسبة الحضور لكل محاضرة، الأوائل، والطلاب المحتاجين متابعة.
- **توزيع الدرجات**: يحدد كل بند بكام درجة ومحسوب من أنهي تقييمات، مثلاً:
  | البند | الدرجة | من |
  |---|---|---|
  | الشيتات | 10 | أفضل 3 من 4 شيتات |
  | الكويزات | 5 | كويز 1 + كويز 2 |
  | الميدترم | 20 | الميدترم |
  | الحضور | 10 | نسبة الحضور × 10 |

  والسيستم بيحسب درجة كل بند والمجموع النهائي والتقدير تلقائياً.
- **تصدير Excel حقيقي (.xlsx)**: منسّق بالعربي، وفيه درجة كل تقييم والحضور وبنود التوزيع والمجموع كـ**معادلات Excel** (لو عدّلت درجة في الملف المجموع بيتحدث)، ومعاه شيت لتوزيع الدرجات وشيت للإحصائيات.
- **فتح الحضور بالـ QR**: شاشة للبروجيكتور فيها QR **بيتغير كل 15 ثانية** (عشان محدش يصوّره ويبعته لزميله) وعدّاد حضور لحظي، ويتقفل تلقائياً بعد المدة المحددة. وتقدر تسجل حضور/غياب يدوي.

### ⏰ الجدول والتذكيرات والحضور التلقائي
- لكل مادة **مواعيد أسبوعية** (محاضرة / سكشن / معمل) بالمكان والسكشن والمعيد المسؤول.
- **تذكير قبل الموعد** (مثلاً 30 دقيقة) للطلاب (طلاب السكشن بس لو الموعد سكشن) وللدكتور أو المعيد.
- بعد بداية الموعد بمدة محددة (مثلاً 10 دقائق):
  - **تذكير المحاضر**: يوصله إشعار "وقت تسجيل الحضور"، ضغطة واحدة تفتح الحضور وتعرض الـ QR، أو
  - **حضور تلقائي**: الحضور بيتفتح لوحده ويوصل للمحاضر رابط شاشة الـ QR.
  - وفي الحالتين **يتقفل تلقائياً** بعد المدة المحددة.

### 🏛️ إدارة الكلية (Admin)
- الأقسام، والطلاب والدكاترة والمعيدين، و**كل مستخدم له كلمة سر خاصة** (بتتولد تلقائياً، والمستخدم لازم يغيرها أول دخول).
- **استيراد الطلاب من Excel** (.xlsx أو .csv، أو نسخ ولصق من الشيت)، مع تحميل ملف كلمات السر.
- إنشاء المواد، إسناد الدكتور والمعيدين، و**تسجيل دفعة كاملة** (قسم + فرقة) في المادة بضغطة.
- **إعلانات الكلية**: إشعار لكل الكلية أو قسم أو فرقة.

### 🔔 الإشعارات
إشعار فوري داخل التطبيق + **إشعارات الموبايل/الكمبيوتر (Web Push)** لما: ينزل شيت أو إعلان أو محاضرة، تنزل الدرجات، يتفتح الحضور، يقرب موعد تسليم (قبلها بـ 24 ساعة)، يقرب موعد محاضرة/سكشن، إنذار غياب، أو توصل رسالة.

## التشغيل

المتطلبات: **Node.js 20+**

```bash
npm run setup     # تثبيت المكتبات
npm run seed      # (اختياري) بيانات تجريبية: أقسام ومواد وطلاب ودرجات وحضور وجدول
npm run dev       # الخادم على :4000 والواجهة على http://localhost:5173
```

### حسابات تجريبية (بعد `npm run seed`)

| الواجهة | اسم المستخدم | كلمة السر |
|---|---|---|
| إدارة الكلية | `admin` | `admin123` |
| دكتور | `d.ahmed` | `doctor123` |
| معيد | `ta.mona` | `ta123456` |
| طالب (حاسبات - الفرقة الثالثة) | `2023001` | `student123` |

بدون `seed` بيتعمل حساب أدمن تلقائياً (`admin` / `admin123` أو من `ADMIN_USERNAME` / `ADMIN_PASSWORD`) ويُطلب تغيير كلمة السر أول دخول.

### النشر (Production)

```bash
npm run build && npm start          # خادم واحد على :4000 بيقدّم الواجهة والـ API
# أو
docker compose up -d --build
```

البيانات (قاعدة البيانات SQLite والملفات المرفوعة) بتتحفظ في `DATA_DIR` (في Docker: الـ volume `/data`). خد منها نسخة احتياطية بانتظام.

> ⚠️ **لازم HTTPS** على السيرفر الحقيقي: الكاميرا (مسح الـ QR) وإشعارات الموبايل مش بتشتغل في المتصفح إلا على HTTPS (أو localhost). استخدم Caddy / Nginx + Let's Encrypt أو أي استضافة بتوفر HTTPS. على الآيفون الإشعارات بتشتغل بعد "إضافة إلى الشاشة الرئيسية".

الإعدادات المتاحة في [`.env.example`](.env.example).
