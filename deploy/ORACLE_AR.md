# 🚀 تشغيل البوابة على Oracle Cloud (مجاناً) — خطوة بخطوة

الهدف: لينك ثابت `https://اسمك.duckdns.org` يفتح على أي موبايل، شغّال 24 ساعة، ومجاني.
الوقت المتوقع: حوالي 45 دقيقة أول مرة.

> ✋ قبل ما تبدأ: لازم الـ Pull Request يكون **اتعمله Merge** في GitHub (زرار أخضر واحد)، لأن السيرفر بياخد الكود من فرع `main`.

---

## 1) اسم الموقع المجاني (DuckDNS) — 3 دقايق
1. افتح https://www.duckdns.org وسجّل دخول بحساب Google أو GitHub.
2. في خانة **sub domain** اكتب اسم (مثلاً `psu-eng`) واضغط **add domain**.
3. انسخ الـ **token** اللي ظاهر فوق في الصفحة واحتفظ بيه (هتحتاجه في الخطوة 5).

## 2) حساب Oracle Cloud — 10 دقايق
1. افتح https://www.oracle.com/cloud/free واضغط **Start for free**.
2. اكتب بياناتك. هيطلب **كارت بنكي للتحقق فقط** (بيحجز حوالي دولار ويرجعه) — الخطة المجانية **Always Free** مش بتسحب فلوس.
3. في **Home Region** اختار أقرب منطقة (مثلاً **Saudi Arabia West (Jeddah)** أو **UAE East (Dubai)**) — مينفعش تتغير بعد كده.

## 3) إنشاء السيرفر — 10 دقايق
1. من القائمة: **Compute ← Instances ← Create instance**.
2. **Image**: اضغط Change image ← **Ubuntu** ← **Canonical Ubuntu 22.04**.
3. **Shape**: اضغط Change shape ← **Ampere** ← **VM.Standard.A1.Flex** واختار **1 OCPU و 6 GB** (مكتوب جنبها Always Free-eligible).
   - لو ظهرت رسالة *Out of capacity*: جرّب تاني بعد شوية، أو اختار **VM.Standard.E2.1.Micro** (برضه مجاني — السكريبت بيتعامل معاه).
4. **Networking**: سيبها زي ما هي، واتأكد إن **Assign a public IPv4 address** متعلّم عليها.
5. **Add SSH keys**: اختار **Generate a key pair for me** واضغط **Save private key** (هينزل ملف — احتفظ بيه).
6. اضغط **Create** واستنى لحد ما الحالة تبقى **Running** (خضرا).
7. انسخ **Public IP address** من صفحة السيرفر.

## 4) فتح بورت 80 و443 (عشان الموقع يفتح) — 3 دقايق
1. في صفحة السيرفر، تحت **Primary VNIC** اضغط على اسم الـ **Subnet**.
2. اضغط على **Default Security List**.
3. **Add Ingress Rules** واملأ:
   - Source CIDR: `0.0.0.0/0`
   - IP Protocol: `TCP`
   - Destination Port Range: `80,443`
4. اضغط **Add Ingress Rules**.

## 5) التثبيت بأمر واحد — 10 دقايق
1. في Oracle، اضغط أيقونة **Cloud Shell** (`>_`) فوق على اليمين — هتفتح شاشة أوامر في المتصفح.
2. من قائمة Cloud Shell (⚙️ أو ☰) اختار **Upload** وارفع ملف المفتاح اللي نزل في الخطوة 3.
3. اكتب (بدّل `IP` بالرقم اللي نسخته، واسم الملف لو مختلف):
   ```bash
   chmod 600 ssh-key-*.key
   ssh -i ssh-key-*.key ubuntu@IP
   ```
   لو سألك `Are you sure…` اكتب `yes`.
4. انسخ الأمر ده والصقه واضغط Enter:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/Aliwaly16122000/Ali-Waly/main/deploy/install.sh | sudo bash
   ```
5. هيسألك:
   - **اسم الموقع**: `psu-eng.duckdns.org` (اللي عملته في الخطوة 1)
   - **توكن DuckDNS**: الصق التوكن (بيربط الاسم بالسيرفر تلقائياً)
   - **اسم مستخدم وكلمة سر الأدمن**: اختار كلمة سر قوية (8 حروف على الأقل)
   - **إيميلك**
6. استنى 5–10 دقايق لحد ما يظهر **✅ التطبيق شغال!** ومعاه اللينك.

## 6) أول دخول وتجهيز التجربة على مادة واحدة
افتح اللينك وسجّل بحساب الأدمن (هيطلب تغيير كلمة السر)، وبعدين بالترتيب:
1. **إعدادات الكلية**: ارفع لوجو الجامعة، واكتب اسم الجامعة والكلية، وحدد الترم الحالي وتاريخ بدايته ونهايته.
2. **الكليات والقيادات**: عدّل اسم الكلية لو محتاج.
3. **الأقسام**: أضف قسمك.
4. **المستخدمون ← استيراد من Excel**: حمّل النموذج واملأ الدكتور والمعيدين وطلاب المادة، وارفعه.
5. **المواد والتسجيل**: أنشئ المادة ← أسند الدكتور والمعيدين ← سجّل الطلاب (دفعة كاملة بضغطة).
6. من صفحة المادة: حدد **المواعيد** (المحاضرة والسكاشن) و**توزيع الدرجات**.
7. من إدارة المادة اضغط **كروت دخول المادة** ← اطبع وقص ووزّع (كل طالب الكارت بتاعه بس).
8. الطلاب: يمسحوا الـ QR اللي على الكارت ← يدخلوا ويغيّروا كلمة السر ← **إضافة للشاشة الرئيسية** ← من "حسابي" يفعّلوا الإشعارات.

## بعد كده
- **تحديث البرنامج لما أضيف حاجات جديدة** (البيانات بتفضل زي ما هي):
  ```bash
  sudo bash /opt/engportal/src/deploy/update.sh
  ```
- **النسخ الاحتياطي**: بيتعمل تلقائي كل يوم، ونزّل نسخة على جهازك كل أسبوع من **إعدادات الكلية ← النسخ الاحتياطي**.
- **النقل لسيرفرات الكلية لاحقاً**: نفس الأمر على سيرفرهم، وبعدين ننقل ملف قاعدة البيانات (`/opt/engportal/data`) — كل حاجة هتكمل من مكانها.
